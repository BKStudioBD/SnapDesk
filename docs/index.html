SnapDesk

One lightweight, fully native macOS menu-bar app — capture, annotate, OCR, color-pick, clipboard, screen-record and clean, all in one place.

Screenshots, OCR, color picking, clipboard history and screen recording — one native app, nothing else to install.

Apple Silicon & Intel · macOS 14+ 100% on-device · no network Native · tiny binary Open source

Install in one command

Paste this into Terminal — it downloads, installs to Applications, clears the Gatekeeper flag, and launches. No drag, no warning.

curl -fsSL https://raw.githubusercontent.com/BKStudioBD/SnapDesk/main/install.sh | bash

Prefer manual? Grab the ZIP, move SnapDesk to Applications, and right-click → Open the first time.

Everything it does

📸 Capture & Annotate ⌃1

Drag a region or click a window to snap it, then mark up with arrows, boxes, blur, steps, text and spotlight. Copy, save or pin on top.

🔤 Grab Text (OCR) ⌃2

Drag over any text on screen — recognized on-device (Apple Vision) and copied instantly. Only the selected area dims.

🎨 Pick a Color ⌃3

Magnified eyedropper → copies the color as HEX or RGB, and keeps your last 16 picks as swatches.

📋 Clipboard History ⌃4

Searchable history of text & images. One click pastes into the app you came from; double-click just copies. Passwords never saved.

🎥 Record Screen ⌃5

Region or full screen, with audio, mic, webcam bubble, on-device captions and privacy blur. Trim timeline with mid-video cuts + export.

📜 Scrolling Capture ⌃6

Auto-scroll a long page hands-free — SnapDesk stitches it into one tall image and opens the result.

🔁 Grab Text Again ⌃7

Re-reads the last OCR area with no drag — the quick way to keep copying a value that changes.

🗂 Text Stack ⌃8

Collect several OCR grabs into one clipboard payload, then paste them all at once.

🧹 Cleaner

Dashboard of CPU, memory, disk and network, plus three ways to get space back: grouped caches, rebuildable build folders (node_modules, DerivedData, .build), and a deep app uninstaller. Everything goes to the Trash.

⚙️ Built for macOS

Menu-bar only, rebindable shortcuts, launch at login, one crisp custom icon, instant UI. Pure Swift on Apple frameworks — no dependencies.

🔒

Private by design

OCR, captions, image processing and cleaning all run on your Mac. SnapDesk has no network code — nothing is ever uploaded. Clipboard history ignores anything marked secret, so passwords from your password manager are never stored.
